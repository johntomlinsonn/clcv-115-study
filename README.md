# CLCV 115 — Study Site (Exam 1 & Exam 2)

A retrieval-practice study site for CLCV 115. **Exam 1** (Powell, *Classical Myth* ch. 1–9 + lectures) is built from `docs/claude-study-website-design.md`; **Exam 2** (Powell ch. 10–14, 16–18 + lectures) from `docs/exam2/` (plan: `docs/exam2/00-website-plan.md`).

**Open it:** double-click `index.html` (works from `file://`), or use the GitHub Pages deployment (`.github/workflows/pages.yml` deploys `main`). No build step.

**Choosing an exam:** the first visit shows an exam picker; afterwards the **Exam 1 / Exam 2** switch in the top bar (or `index.html?exam=1` / `?exam=2`) changes exam. Each exam loads only its own data and keeps its own progress (`clcv115_v1` for Exam 1 — unchanged — and `clcv115_e2_v1` for Exam 2). Both use exactly the same modes below.

## Exam 2 content
- 137 study-guide terms in the guide's wording + 88 lecture/Powell terms + **176 course-reading-question recall cards** (the professor: “most test questions are based on these”).
- 342 hand-written questions: 24 in-class + 47 Oct 27 review + ~195 built from the reading questions + 76 lecture-slide/Powell questions; items with unconfirmed answers are flagged `nomock` (learning modes only).
- 13 tested images with label pins; 10 map places on three maps (new Attica close-up, the Aegean, Greece → Mesopotamia); 10 story clusters; 9 lecture pages; family trees, match games, cheat sheet.
- Mock exam: 75 Q / 50:00, ~55% reading-question items, balanced across the ten clusters.
- Data: `data/exam2/*.js` (`stories.js` is generated by `tools/exam2/build_stories.py` from `docs/exam2/06-story-clusters.md`); maps by `tools/build_maps.py`.

## What's inside
| Route | Mode |
|---|---|
| `#/home` | Countdown to the end of the CBTF window, "CBTF booked?" checkbox, readiness %, progress, next best action, 1–2 day study protocol |
| `#/learn` | Story Mode — the 9 story clusters, each with a 3-question check |
| `#/lectures` | Lecture Notes for every lecture Aug 25 – Sept 22: slide decks (Aug 27, Sept 1, 3, 8, 10, 15) plus the student's own notes, in-class questions, quick checks and “Check this” corrections |
| `#/flash` | Flashcards (term ↔ meaning, images, Roman names, optional fact cards) with Leitner boxes, recall timer, type-the-answer |
| `#/pictures` | Picture Quiz: name it, which clue, label the object (pins), reverse, zoom challenge, study gallery |
| `#/map` | Map Test: what is marked (★/◯), click to locate, place ↔ meaning, explore |
| `#/quiz` | Topic quiz (hand-written + auto-generated), learning or test mode, 40 s pace bar |
| `#/review` | The 40 review-lecture questions |
| `#/mock` | 75 questions / 50:00, flags, navigator, auto-submit, history |
| `#/errors` | Fix-My-Mistakes log + drill |
| `#/tree`, `#/match`, `#/cheatsheet`, `#/resources` | Family tree + quiz, match games, printable cheat sheet, links + Powell-index lookup drill |

Keyboard: `1–4`/`a–d` answer · `Enter` next · `F` flag · `←/→` navigate (test mode) · `Space` flip card · `1–4` rate card.

## Notes
- Progress lives in `localStorage` (`clcv115_v1`); use **Export/Import** in the footer to move it between devices. The site still works if storage is blocked.
- Maps are static, unlabeled SVGs generated from Natural Earth coastlines (`python3 tools/build_maps.py land-10m.json`, data from `npm pack world-atlas@2`): an Aegean close-up and a Greece→Mesopotamia view with the Tigris and Euphrates. No map API, no key, works offline.
- `data/lectures.js` holds the lecture-slide content: 64 extra terms (own flashcard deck), extra facts merged into study-guide terms, and 98 lecture questions (tag `lecture`, ~40% of the mock's hand-written share). `data/notes.js` adds the Sept 8 / Sept 10 decks and the student's notes (Aug 25 – Sept 22): 45 more terms, 53 more questions, and per-lecture “From your notes” sections. No deck was provided for Sept 17 or the review week; those pages come from the notes.
- `data/terms.js`, `data/stories.js` and `data/questions.js` are generated from the spec: `python3 tools/build_data.py`. `data/images.js` and `data/places.js` are hand-edited.
- Self-test: open `index.html?exam=1&selftest` or `?exam=2&selftest` and check the console (verifies every question and option shuffling).

For studying *before* the exam only — don't open this (or anything else) during a CBTF exam.
