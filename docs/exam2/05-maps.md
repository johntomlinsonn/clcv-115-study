## Build notes
- Exam-1 maps are static SVGs from `tools/build_maps.py` (Natural Earth `land-10m.json` from `npm pack world-atlas@2`): `aegean` (19.3–28.7 E, 34.6–42.0 N) and `wide` (11–50 E, 27.5–44.5 N). Every Exam-2 place fits on these **except that Eleusis/Athens/Thebes/Megara/Corinth crowd together** → add a third map, **`attica`** (≈ 22.3–24.2 E, 37.3–38.6 N), generated by the same script. If the network blocks `npm pack` during the build, fall back to tighter tolerances + the "what is marked here?" (a–d) format, which doesn't need precise clicking.
- Map formats to keep (same as Exam 1): **What is marked (★/◯)?** a–d · **Click to locate** · **Place ↔ meaning** · **Explore**.
- Blank maps from the slides are saved in `assets/exam2/slide-images/` (`map-greece-blank-handdrawn.jpg` = review slide 21; `map-ancient-greece-blank.jpg` = Oct 15 Q1; `map-crete-greece-italy.jpg` = review slide 92) for a "looks like the lecture" mode or as a visual reference. The markers/letters on those slides were PowerPoint shapes and are not in the images.
